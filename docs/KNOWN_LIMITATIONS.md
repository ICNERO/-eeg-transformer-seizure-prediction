# 已知限制与后续复现条件

本页记录现有研究源码的行为。归档整理保留模型结构与核心信号处理参数，以下问题仍需在新的实验中处理与验证。

| 范围 | 现有实现 | 对复现与结果解释的影响 |
| --- | --- | --- |
| 监督目标 | `EEGDataset` 按患者/对照目录赋标签，不读取发作阶段标签 | 当前是患者/对照分类；尚未建立提前预测的目标、预测时域与评估协议 |
| 频率契约 | 患者流程在 128 Hz 重采样后仍生成最高 80 Hz 的自定义时频点；对照流程限制到 51.2 Hz | 80 Hz 超过该采样率的 64 Hz Nyquist 频率；两类频率网格不同，需要统一到合法、相同的网格 |
| 分段策略 | 患者按注释分段，对照每个 EDF 只取前 60 秒 | 不同设备、记录来源和处理策略可能形成域混杂 |
| 通道语义 | 各文件独立选择 8 个通道索引 | 相同模型输入位置可能对应不同电极；需要建立统一通道映射 |
| 多 epoch 文件 | 较新加载器无条件取第一个 epoch，再下采样并截断到 240 点 | 多数 epoch 未进入模型，每个文件的有效时间也被截短 |
| 较旧模型 | 旧版对 `E>1` 的轴处理把 epoch 与 channel 混用 | 旧版保留作历史归档，不作为当前推荐入口 |
| 位置编码 | 计算 RoPE 的 cos/sin，但注意力没有施加它们 | 当前 Transformer 没有实际启用源码所描述的旋转位置编码 |
| Euler 模块 | 时间均值池化后以序列长度 1 输入手写 Euler 更新；`odeint` 未被调用 | 应描述为 ODE-inspired 更新模块；无法据此证明原始时间序列动力学建模能力 |
| 时频实现 | 历史“Stockwell”函数按频率改变 Gaussian 窗宽 | 尚未与标准 S-transform 做数值对照，归档称为自定义 Stockwell-like 特征 |
| QPSO | 更新时选择数硬编码为 8，初始化群体被同一 top-n 子集覆盖 | `--n_select` 的其他取值不可靠，初始群体多样性受限；归一化无 epsilon，常量输入可能产生 NaN |
| 数据划分 | 按受试者划分 train/val；缺少统一随机种子、分层和固定划分清单 | 小样本时验证集可能为空；当前代码没有自动建立独立测试集 |
| 选择与评估 | 通道选择可在完整文件上使用阶段标签和内部随机划分 | 存在标签信息进入后续验证预处理的潜在泄漏风险；重新实验应先固定受试者划分，仅在训练数据拟合选择策略 |
| 读取失败 | 历史加载器可用零数组替代读取失败文件 | 训练前应检查数据完整性，避免把代替数组当成有效 EEG |
| `evaluate` | 评估传入目录的所有匹配文件 | 使用者负责建立独立受试者测试目录并检查与训练集互斥 |

## 运行与内存成本

历史 `EfficientAttention` 仍显式生成 `(B, heads, T, T)` 注意力矩阵，其时间维成本随 `T²` 增长。CNN 的 512→1024 通道卷积及 1024→1024 的 40 点频率卷积也是主要成本。文件加载使用 `np.load`，部分预处理步骤会分配完整复数时频数组，不能仅凭“内存处理”或“Efficient”类名判断资源开销。

## 重新实验需要补齐

1. 数据来源、受试者映射、采样率、通道布局与标签真值。
2. 统一的合法频率网格和患者/对照预处理协议。
3. 明确目标：患者/对照分类，或真正的发作提前预测；后者还需定义预测时域与评价方案。
4. 固定受试者划分、随机种子和依赖环境；通道选择与预处理拟合范围限于训练集。
5. 独立测试数据、权重和可审查的评价输出。

原始测试数据缺失期间，仓库的验证只支持代码归档完整性与合成输入结构检查，不支持性能、泛化能力或临床有效性结论。
